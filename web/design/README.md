# Ikon

Vejret-ikonet (forslag B, "Dråbe"): glasagtig regndråbe med lille sol på blå himmelgradient.

- `icon-rounded.svg` — med afrundede hjørner (favicon, manifest "any")
- `icon-square.svg` — fuld flade (Apple touch-ikon, Android "maskable"; systemet runder selv)

De færdige filer i `../public/` er renderet herfra (cairosvg): `favicon.svg`, `favicon.ico` (16/32/48), `favicon-16/32.png`, `apple-touch-icon.png` (180), `icon-192/512.png`, `icon-maskable-512.png`.
